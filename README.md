# بكم؟ — Flutter

تم تحويل المشروع المرفق من Next.js/React إلى تطبيق Flutter بلغة Dart.

## التشغيل
1. ثبّت Flutter SDK وتأكد من إعداد Android Studio أو Xcode.
2. افتح مجلد المشروع `bikam_flutter`.
3. نفّذ:
   ```bash
   flutter pub get
   dart run flutter_launcher_icons
   flutter run
   ```
4. لبناء APK:
   ```bash
   flutter build apk --release
   ```
   الملف الناتج يكون عادةً في `build/app/outputs/flutter-apk/app-release.apk`.

## المنصات
الواجهة مكتوبة بـ Flutter وتعمل على Android و iOS والويب وسطح المكتب. اختيار الصور مدعوم حسب إمكانات المنصة.
لإنشاء مجلدات المنصات التي تحتاجها (إن لم تكن موجودة) استخدم `flutter create --platforms=android,ios,web,windows,macos,linux .`.

## الوظائف الموجودة
- الأسواق الأربعة عشر الواردة في المشروع الأصلي.
- إضافة المنتجات مع الاسم والحجم والسعر وسعر الجملة.
- اختيار صورة من المعرض أو التقاط صورة بالكاميرا.
- حفظ محلي للمنتجات والإعدادات.
- بحث تقريبي عن المنتج اعتماداً على بصمة الصورة (aHash و dHash ومتوسط اللون).
- العربية والإنجليزية، الوضع الفاتح والداكن، وتغيير حجم النص.
- أيقونة التطبيق تستخدم الصورة المرفقة.

## ملاحظة مهمة عن الخادم
المشروع الأصلي كان يعتمد على Next.js API وقاعدة PostgreSQL عبر `DATABASE_URL`. نسخة Flutter الحالية مستقلة وتخزن البيانات محلياً على الجهاز باستخدام SharedPreferences؛ لذلك لا تتزامن البيانات تلقائياً بين الأجهزة ولا تتصل بقاعدة البيانات القديمة. يلزم إنشاء API آمن مستقل إذا أردت مشاركة قاعدة بيانات مركزية. لا تضع بيانات اتصال PostgreSQL أو كلمات المرور داخل تطبيق الهاتف.
